# Mutsu OS — getting started

This guide is on your computer. You do not need a network to read it.

## Open apps
Press Super+Space (the Windows or Command key, then Space) to open Mutsu Search.
Type an app name and press Enter.

## Look
The top-left Mutsu menu switches between Calm Japandi and Cyberpunk.
Follow System leaves your own theme alone.

## Keyboard
The setup wizard asks which keyboard you have.

- Windows keyboard, Mac shortcuts: Super+C copies, Super+V pastes.
- Windows keyboard, standard shortcuts: only Super+Space is added.
- Mac keyboard: Command acts as Super.

You can change this later. It is not forced on.

## Updates
Open Mutsu Updater from the app grid. It updates the system and Flatpaks.

## Help
Mutsu Mechanic can check audio, list apps, and launch programs after you approve.
It will not change the system without asking.
