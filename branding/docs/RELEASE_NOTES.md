# Mutsu OS 1.0 — Shibui

Shibui is the first named Mutsu release: quiet, finished, and usable without a first-boot download.

- Japandi is the default look. Cyberpunk is the night theme.
- Mutsu Search opens with Super+Space.
- The local model and Newelle start with the system. You do not open Newelle or type a key.
- Tablet mode uses the Springboard, the floating dock, and the bottom swipe.
