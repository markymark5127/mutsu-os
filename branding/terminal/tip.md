Want to find an app or troubleshoot a problem? Use Mutsu Search (Super+Space) for apps, files and optional AI assistance.
Need help with Mutsu OS? Read the built-in guide using the Mutsu Documentation app.
Updating Mutsu OS? Open Mutsu Updater, or run `ujust update` to update system packages and apps.
Want to customize the desktop? Choose Calm Japandi or Cyberpunk from the Mutsu menu.
